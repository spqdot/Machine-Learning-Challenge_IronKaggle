# Machine Learning Challenge – IronKaggle

## Overview

This project was developed as part of an **Ironhack Machine Learning Challenge** focused on applying machine learning and data analysis techniques to a real-world prediction problem.

The project covers the complete machine learning workflow, from **data exploration and preprocessing to model development, evaluation, and prediction generation**.

## Project Objectives

* Explore and understand the provided dataset
* Perform data cleaning and preprocessing
* Conduct exploratory data analysis (EDA)
* Identify relevant patterns and relationships in the data
* Develop and evaluate machine learning models
* Generate predictions for unseen data
* Save the final predictions for further evaluation

## Workflow

The project follows these main steps:

1. **Data Loading** – Imported and inspected the available training and prediction datasets.
2. **Data Exploration** – Examined data structure, distributions, missing values, and relevant features.
3. **Data Preprocessing** – Prepared the data for machine learning by handling data-quality and feature-related requirements.
4. **Feature Analysis** – Investigated the relationship between features and the target variable.
5. **Model Development** – Applied machine learning techniques to develop predictive models.
6. **Model Evaluation** – Compared model performance using appropriate evaluation metrics.
7. **Prediction** – Generated predictions on the required dataset.
8. **Output** – Saved the final predictions in `predicted_sales.csv`.
